# Game Controller Website

Static product and legal website for the Game Controller iPhone and iPad app.

## Public paths

- `/` - website entry
- `/static/` - product website
- `/PrivacyPolicy/` - privacy policy
- `/UserAgreement/` - user agreement
- `/privacy/` and `/terms/` - compatibility aliases

## Local preview

```bash
npm run dev
```

## Validate and build

```bash
npm test
```

The build output is written to `dist/`.
