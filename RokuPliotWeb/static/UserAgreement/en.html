1. Service and eligibility

Game Controller is an iPhone and iPad utility for controlling compatible Roku streaming players and Roku TVs over a local network. Features may include device discovery, manual local IP connection, button controls, touchpad gestures, installed-channel display, channel favorites, channel launch requests, haptic feedback, and a game-control layout.

6. Game controls

Game mode provides a joystick-style movement area and quick actions for supported interactions. Support depends on the active Roku application, the integration exposed by that application, network latency, and the Roku model. Game mode may fall back to Roku menu navigation when compatible game input is not active.

Game Controller does not guarantee competitive performance, continuous input delivery, diagonal movement in every game, or compatibility with games that do not implement the expected control interface. Use the standard remote when a game or menu does not respond as expected.
